# Code of Conduct
We want Storage to be a welcoming project. Be kind, assume good intent, and keep discussion about the work. Harassment, discrimination, personal attacks, and publishing others' private information are not acceptable.

Maintainers may edit or remove comments, commits, issues and PRs that break these rules, and may ban repeat offenders. To report a problem, use GitHub's *Report content* feature or contact a maintainer privately through their GitHub profile.

This text is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
